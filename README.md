# Ironwood Protocol
Önálló, eredeti, offline böngészős taktikai FPS prototípus.

## Indítás
1. Csomagold ki a projektet.
2. Nyisd meg az `index.html` fájlt modern Chrome/Edge/Firefox böngészőben.
3. Nyomd meg a PLAY gombot, majd kattints a játékmezőre a kamera vezérléséhez.

## Irányítás
WASD mozgás, egér célzás/lövés, Shift sprint, Ctrl guggolás, Space ugrás (a mozgásrendszer fenntartja a billentyűt, de a jelenlegi egyszerű motorban az ugrás nem ad fizikai függőleges mozgást), R újratöltés, 1/2/3 fegyver, E objektív-interakció.

## Megjegyzés
A projekt szándékosan külső assetek és hálózati függőségek nélkül készült, így helyben futtatható. A renderer egy önálló, performance-barát raycast megjelenítést használ, a botok pedig egyszerű állapotgépes taktikai AI-t.
